# Практична робота 1: Вступ до IoT та SMART-технологій

**Дисципліна:** Технології IoT та SMART-технології  
**Варіант:** 1 (Розумна теплиця площею 200 м²)  
**Мета:** Спроєктувати систему автоматичного вирощування з урахуванням автономності, безпеки та обсягів даних.

---

## 1. Архітектура системи

Архітектура побудована за чотирирівневою моделлю IoT. Рівень сприйняття комунікує зі шлюзом через енергоефективний протокол Zigbee (ідеально для площі 200 м²), а шлюз передає дані в хмару через Wi-Fi/Ethernet за протоколом MQTT.

    subgraph 2. Мережевий рівень

    Net2 --> Cloud
    Cloud --> App1 & App2
